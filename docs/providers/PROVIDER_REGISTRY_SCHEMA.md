# Provider Registry Schema

Required registry properties:

- identity
- owner
- official documentation URL
- official terms/policy URL
- changelog URL
- access status
- commercial-use status
- authentication flow
- scopes
- capabilities
- quotas/rate rules
- retry policy
- attribution/branding
- storage/cache limits
- raw payload retention
- media/embed restrictions
- market restrictions
- user consent
- revocation/deletion
- feature flag
- kill switch
- fallback
- last policy review
- next review date
- approval evidence
- known risks

Provider status:
- research
- blocked
- sandbox
- approved
- degraded
- suspended
- retired
