# SoundCloud

Status: P1 gated.

## Potential use

- track/user catalog data;
- canonical SoundCloud URLs;
- embedded player;
- authorized user interactions supported by the API.

## Rules

- Obtain approved credentials under current eligibility.
- Follow OAuth 2.1/current official authorization guidance.
- Use the official embedded player.
- Do not download or re-host streams.
- Follow current identifier field types; do not assume numeric IDs.
- Use the official OpenAPI specification where available.
- Track API and streaming-format changelogs.
- Artist Pro or other account eligibility may be required for self-service keys.
- Keep SoundCloud optional and disable gracefully.

Official references:
- https://developers.soundcloud.com/
- official OpenAPI repository announced by SoundCloud
