# Deezer

Status: P2 research/gated.

## Potential use

- catalog lookup;
- deep links;
- official widgets/plugins.

## Rules

- Confirm that SongChart can obtain and retain an app/API key under current terms before coding.
- Prefer official widgets for playback.
- Treat market availability as dynamic.
- Do not scrape Deezer pages.
- Do not use Deezer as a canonical metadata dependency.
- Create the adapter only after endpoint, auth, quota, storage and attribution terms are captured in the registry.
