# Cover Art Archive

Status: recommended P0 artwork provider.

## Use

Artwork associated with MusicBrainz release/release-group identities.

## Rules

- Resolve artwork through MBIDs, not title search.
- Store source and image type/front/back flags.
- Cache only under current service/licensing rules.
- Generate first-party renditions only when permitted.
- Keep an artwork fallback because coverage is incomplete.
- Never infer ownership or official status from image presence.
- Avoid hotlink assumptions; review current access and attribution before production.
