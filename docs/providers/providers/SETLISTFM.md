# setlist.fm

Status: P3 gated.

## Potential use

Historical concert setlists linked to MusicBrainz artist identities.

## Rules

- Obtain an API key and confirm commercial permission.
- Follow required source links and attribution.
- Respect cache/storage constraints.
- Keep user-edited setlist data distinct from canonical recording/release data.
- Do not infer that a performed song corresponds to a specific studio recording.
- Do not copy page content outside the approved API.
