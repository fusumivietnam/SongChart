# Songkick

Status: P3 commercial integration only.

## Potential use

Upcoming/past concerts, artists, venues and locations.

## Current access

Official developer material states a partnership agreement and license fee are required, and hobby/student applications are not currently approved.

## Rules

- Do not implement until a signed agreement and API key exist.
- Follow required “Concerts by Songkick” attribution and resource links.
- Cache only for the duration permitted by the signed/current terms.
- Respect exclusivity/non-combination restrictions in the applicable agreement.
- Keep events in a separate bounded module.
- Never mix provider event data with manually entered events unless the license explicitly permits it.
