# Discogs

Status: P2 specialist provider pending access and licensing review.

## Potential use

- physical releases and editions;
- masters;
- labels;
- catalog numbers;
- community-contributed credits.

## Rules

- Preserve distinction between master and release.
- Do not merge Discogs releases with digital releases automatically.
- Treat marketplace/pricing as a separate prohibited-by-default capability.
- Verify current authentication, rate limits, image usage, attribution, commercial and caching terms.
- Do not scrape Discogs.
- Import asynchronously and retain provenance.
- Require editor review for high-impact merges.
