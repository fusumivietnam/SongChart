# Extension System Roadmap

## E1 — local extension foundation

- database registry;
- install/audit records;
- inspect commands;
- checksum;
- compatibility/dependency checks;
- install disabled;
- enable/disable;
- active release pointer;
- theme preview/activate;
- admin read-only list.

## E2 — managed upgrades

- staged releases;
- snapshots;
- code rollback;
- migration declarations;
- health checks;
- upgrade/rollback commands;
- release cleanup;
- admin upload/upgrade UI.

## E3 — trusted distribution

- publisher registry;
- signatures;
- key rotation/revocation;
- signed first-party packages;
- security scanning;
- update feed.

## E4 — marketplace, chỉ khi thật sự cần

- catalog;
- license/payment;
- publishing workflow;
- vulnerability notices;
- remote updates.
