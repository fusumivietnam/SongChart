# Operational Provider Registry Schema

Required fields:
- category;
- provider;
- purpose;
- owner;
- status;
- official docs;
- privacy/DPA link;
- regions;
- data classes sent;
- authentication;
- SDK/API versions;
- quotas;
- cost guardrails;
- webhook signing;
- retry/idempotency;
- retention;
- deletion/export;
- consent category;
- fail-open/fail-closed;
- feature flag;
- fallback;
- secret rotation;
- last review;
- next review;
- incident runbook;
- exit/migration plan.
