# Scope Control

## MVP

- Artist, release, recording và credits.
- Provider identities và outbound links.
- Search cơ bản từ database.
- SEO pages, canonical URL, sitemap và structured data.
- Local account, social login tùy provider được duyệt.
- Favorites và user collections.
- YouTube embed khi policy cho phép.
- Admin editorial workflow.
- Provider compliance registry và audit log.

## Post-MVP

- Meilisearch.
- Automated metadata enrichment.
- Recommendation graph.
- Public user playlists.
- Comments/community.
- Additional embeds.
- Provider account sync.

## Explicitly deferred

- Microservices.
- Kubernetes.
- Event streaming platform.
- Dedicated graph database.
- Data warehouse.
- Native mobile apps.

Mọi feature mới phải được thêm vào MVP/Post-MVP/Deferred trước khi code.
