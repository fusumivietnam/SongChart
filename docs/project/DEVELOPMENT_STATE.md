# Development State

This path is a compatibility pointer only and does not own mutable progress.

Use `docs/project/generated/development-state.json` as the machine/AI authority and `docs/project/generated/DEVELOPMENT_STATE.md` as its human-readable projection.

Live branch, pull request, exact head SHA, and verification lifecycle are runtime facts. Resolve them from Git/GitHub at session start with `./songchart ai status --json`.

Update the owning machine authority (`docs/project/engineering/stage-plan.json`, task contract, project knowledge, or consolidation plan). Auto Closure regenerates the projections.
