# UI Task Checklist

## Before coding

- [ ] Read `DESIGN_AUTHORITY.md`.
- [ ] Read the relevant design contract.
- [ ] Identify the canonical page or admin pattern.
- [ ] Locate existing tokens and components.
- [ ] Confirm entity terminology and data states.

## During implementation

- [ ] Reuse shared components.
- [ ] Avoid raw, unapproved colors.
- [ ] Implement loading, empty, error and partial-data states.
- [ ] Implement desktop, tablet and mobile behavior.
- [ ] Preserve keyboard focus and semantic labels.

## Before completion

- [ ] Compare against approved screenshot direction.
- [ ] Confirm provider disclosure and source access where applicable.
- [ ] Document new reusable components.
- [ ] Update the design contract first when a new pattern is necessary.
