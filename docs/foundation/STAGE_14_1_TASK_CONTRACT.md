# Stage 14.1 Task Contract

## Goal
Create provider-neutral typed normalized DTOs and explicit field presence semantics.

## Required
- Four-state field presence value object.
- Typed artist, work, recording, and release DTOs.
- Typed identifier and relationship DTOs.
- Deterministic serialization for ledger persistence.
- Entity type consistency guard.
- Unit, architecture, verifier, and authority documentation.

## Excluded
Validation/quarantine policy, canonical mutation, identity matching, live provider HTTP clients, and admin UI.
